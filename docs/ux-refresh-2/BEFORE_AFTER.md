## O que muda em cada tela

| Tela | Audit | Refresh 1 | Refresh 2 |
|---|---|---|---|
| Início | Checklist mural | Faixa + lista Hoje | Blocos com número grande (4 / 62 / 50 / 9), clicáveis |
| Inbox lista | Mensageiro + Fila de dígitos | Minhas + nomes humanos | Terceira linha: etapa · sem próximo passo. Avatar menor, nome semibold |
| Header | Barra de botões | Assumir + Transferir + Lembrar + Marcar | Desktop: Assumir + Transferir + ⋯. Mobile: Assumir + ⋯ |
| Cockpit | Copilot + formulário | Ordem da Ficha, IA numa linha | Etapa como texto, responsável compacto, passo só no clique |
| Contatos | Tabela admin horizontal | Igual à auditoria | Lista de pessoas + Abrir conversa. Sem tabela |
| Mobile | Desktop espremido | Header ainda em 2 linhas de botões | Conversa na primeira dobra. Contatos em card-row |
