titulo: Tokens de API com nome, validade e revogação
---

Em Tokens de API dá para criar mais de uma chave, cada uma com nome e data
de validade, e revogar uma sem derrubar as outras. O token marcado para ler
o CRM entrega agenda, funil e indicadores ao sistema que o guarda.
